SKS Marketplace Website
Open index.html in a browser.

This is a ready-to-preview front-end marketplace demo for SKS.
It includes search, city filter, categories, post-ad form, image preview,
local listings, login/register UI and seller contact UI.

For a public production website, connect a domain + hosting and add a
server/database, secure authentication, cloud image storage, real chat,
moderation/admin tools and payments.
